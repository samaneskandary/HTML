۱مجموع زوایای مثلث

مجموع زوایای مثلث
$$\cAll \,\triangle ABC \;:\; \alpha + \beta + \gamma = \pi$$
جابه‌جایی موازی
۱ Let $\ell$ be the line through $A$ parallel to $BC$. خطی موازی با ضلع $BC$ از رأس $A$ می‌کشیم — یک خط کمکی.
۲ Since $\ell \parallel BC$ and $AB$ is a transversal: $\angle(\ell, AB) = \beta$ (alternate interior angles). زاویهٔ $\beta$ به‌واسطهٔ زاویه‌های متناوبِ داخلی به خطِ موازی منتقل می‌شود.
۳ Likewise $\ell \parallel BC$ and $AC$ is a transversal: $\angle(AC, \ell) = \gamma$. همین استدلال برای $\gamma$.
۴ At $A$, the three angles $\beta$, $\alpha$, $\gamma$ lie on one side of a straight line, hence $\beta + \alpha + \gamma = \pi$. سه زاویه کنار هم، روی یک خطِ راست قرار می‌گیرند — مجموعشان نیم‌دایره است.
۵ $\therefore\; \alpha + \beta + \gamma = \pi$. مجموعِ زاویه‌های هر مثلث برابرِ $\\pi$ است. ∎

۲قضیه فیثاغورس

فیثاغورس
$$\cAll\;\text{right } \triangle\;\text{with legs } a, b \;\cAnd\; \text{hypotenuse } c \;:\; a^2 + b^2 = c^2$$
بازآراییِ چهار مثلث
۱ Let $S = a + b$. Take a square of side $S$ and place four copies of the right triangle (legs $a, b$, hypotenuse $c$) inside it. چهار نسخهٔ یکسانِ مثلثِ قائم را درون یک مربعِ بزرگ با ضلع $a+b$ می‌چینیم.
۲ Arrangement (A): the four triangles sit at the corners, hypotenuses facing inward. The leftover region is a quadrilateral with all sides $c$ — a square of area $c^2$. چینشِ الف: مثلث‌ها در گوشه‌ها، وترها به‌داخل؛ ناحیهٔ خالی، مربعی با ضلع $c$.
۳ Arrangement (B): the four triangles form two rectangles; the leftover region is two squares of sides $a$ and $b$, with total area $a^2 + b^2$. چینشِ ب: مثلث‌ها دو مستطیل می‌سازند؛ ناحیهٔ خالی، دو مربع با ضلع‌های $a$ و $b$.
۴ In both arrangements: $\text{area(big square)} = 4 \cdot \tfrac{1}{2}ab + \text{area(leftover)}$. در هر دو چینش، مساحتِ مربعِ بزرگ = مساحتِ چهار مثلث + مساحتِ ناحیهٔ خالی.
۵ The big square and the four triangles are identical in (A) and (B), so the leftover areas are equal: $c^2 = a^2 + b^2$. چون مربعِ بزرگ و مثلث‌ها در هر دو چینش یکسان‌اند، ناحیهٔ خالی هم باید برابر باشد.
۶ $\therefore\; a^2 + b^2 = c^2$. فیثاغورس ثابت شد. ∎

۳نامساوی مثلثی

نامساوی مثلثی
$$\cAll\, a, b \in \cR \;:\; |a + b| \le |a| + |b|$$
از تعریفِ قدرمطلق
۱ By definition of $|\cdot|$: $\cAll\, x \in \cR \;:\; -|x| \le x \le |x|$. هر عدد بین $-|x|$ و $|x|$ است — تعریفِ قدرمطلق.
۲ Apply to $a$: $-|a| \le a \le |a|$. برای $a$: $-|a| \le a \le |a|$.
۳ Apply to $b$: $-|b| \le b \le |b|$. برای $b$: $-|b| \le b \le |b|$.
۴ Add the two inequalities: $-(|a| + |b|) \le a + b \le |a| + |b|$. جمعِ نامساوی‌های هم‌جهت، نامساویِ هم‌جهت می‌دهد.
۵ Set $M = |a| + |b|$. Then $-M \le a+b \le M \cImp |a+b| \le M$. اگر $x$ بین $-M$ و $M$ باشد، آن‌گاه $|x| \le M$.
۶ $\therefore\; |a+b| \le |a| + |b|$. نامساویِ مثلثی ثابت شد. ∎

۴قانون کسینوس‌ها

قانون کسینوس‌ها
$$\cAll\,\triangle ABC \;\text{with}\; \gamma = \angle C \;:\; c^2 = a^2 + b^2 - 2ab\cos\gamma$$
تجزیه به دو مثلثِ قائم
۱ Place $A=(0,0)$, $B=(c,0)$, $C=(x,y)$ with $y>0$. Then $|AC|=b$ and $|BC|=a$. مثلث را در دستگاهِ مختصات می‌گذاریم: $A$ و $B$ روی محورِ $x$، $C$ بالاتر.
۲ From $|AC|^2 = b^2$: $x^2 + y^2 = b^2$. From $|BC|^2 = a^2$: $(x-c)^2 + y^2 = a^2$. دو معادله از طولِ دو ضلعِ $b$ و $a$.
۳ Subtract: $(x-c)^2 - x^2 = a^2 - b^2 \;\Rightarrow\; -2cx + c^2 = a^2 - b^2 \;\Rightarrow\; x = \dfrac{b^2 + c^2 - a^2}{2c}$. تفریقِ معادله‌ها $y$ را حذف می‌کند و $x$ را می‌دهد.
۴ Vectors $\vec{CA}=(-x,-y)$, $\vec{CB}=(c-x,-y)$. So $\cos\gamma = \dfrac{\vec{CA}\cdot\vec{CB}}{ab} = \dfrac{-x(c-x)+y^2}{ab} = \dfrac{b^2 - cx}{ab}$. زاویهٔ $\gamma$ از ضربِ نقطه‌ایِ $\vec{CA}$ و $\vec{CB}$ به‌دست می‌آید.
۵ Substitute $x$: $ab\cos\gamma = b^2 - c\cdot\dfrac{b^2+c^2-a^2}{2c} = \dfrac{a^2 + b^2 - c^2}{2}$. با جای‌گذاریِ $x$ و ساده‌سازی، $ab\cos\gamma = \tfrac{a^2+b^2-c^2}{2}$.
۶ Rearrange: $c^2 = a^2 + b^2 - 2ab\cos\gamma$. همان قانونِ کسینوس‌ها.
تعمیمِ فیثاغورس اگر $\gamma = \pi/2$، آن‌گاه $\cos\gamma = 0$ و $c^2 = a^2 + b^2$ — همان فیثاغورس.

۵مجموع دنبالهٔ حسابی

مجموع حسابی
$$S_n = \sum_{k=1}^{n} a_k = \frac{n}{2}\,(a_1 + a_n)$$
ترفندِ گاوس
۱ Write $S = a_1 + a_2 + \cdots + a_n$ and, reversed, $S = a_n + a_{n-1} + \cdots + a_1$. مجموع را یک‌بار از چپ و یک‌بار از راست می‌نویسیم — همان $S$.
۲ Add column-wise: $2S = (a_1 + a_n) + (a_2 + a_{n-1}) + \cdots + (a_n + a_1)$. جمعِ ستونی: $2S$ را به‌صورتِ جمعِ جفت‌های متقارن می‌نویسیم.
۳ Since $\{a_k\}$ is arithmetic: $a_k = a_1 + (k-1)d$ and $a_{n+1-k} = a_1 + (n-k)d$, so $a_k + a_{n+1-k} = 2a_1 + (n-1)d = a_1 + a_n$. هر جفتِ متقارن، جمعِ ثابتی برابرِ $a_1 + a_n$ دارد.
۴ All $n$ pairs equal $a_1 + a_n$, hence $2S = n(a_1 + a_n)$. هر $n$ جفت برابرِ $a_1 + a_n$ است، پس $2S = n(a_1 + a_n)$.
۵ $\therefore\; S = \dfrac{n}{2}(a_1 + a_n)$. فرمولِ مجموعِ دنبالهٔ حسابی. ∎

۶مجموع دنبالهٔ هندسی

مجموع هندسی
$$\sum_{k=0}^{n-1} ar^k = a\,\frac{1 - r^n}{1 - r}, \quad r \cNeq 1; \qquad \sum_{k=0}^{\infty} ar^k = \frac{a}{1 - r}, \quad |r| < 1$$
تفریقِ نسخهٔ شیفت‌یافته
۱ Let $S = a + ar + ar^2 + \cdots + ar^{n-1}$. مجموعِ دنبالهٔ هندسی را $S$ می‌نامیم.
۲ Multiply by $r$: $rS = ar + ar^2 + \cdots + ar^n$. ضرب در $r$ یک گام به‌چپ شیفت می‌دهد.
۳ Subtract: $S - rS = a - ar^n$ (all middle terms cancel). جملاتِ $ar$ تا $ar^{n-1}$ در هر دو طرف هستند و حذف می‌شوند.
۴ Factor: $S(1 - r) = a(1 - r^n)$. Since $r \cNeq 1$: $S = a\,\dfrac{1 - r^n}{1 - r}$. با فاکتورگیری و بخش بر $1-r$ (چون $r \neq 1$) فرمولِ مجموع به‌دست می‌آید. ∎
۵ If $|r| < 1$, then $r^n \to 0$ as $n \to \infty$, so $\sum_{k=0}^{\infty} ar^k = \dfrac{a}{1 - r}$. برای $|r| < 1$، حدِ $r^n$ صفر است و مجموعِ نامتناهی برابرِ $\tfrac{a}{1-r}$ می‌شود. ∎

۷تعداد زیرمجموعه‌ها

زیرمجموعه‌ها
$$|A| = n \;\cImp\; |\mathcal{P}(A)| = 2^n$$
دوسویی با رشته‌های بیتی
۱ Enumerate $A = \{a_1, a_2, \ldots, a_n\}$. مجموعهٔ $A$ را با $n$ عنصر شماره‌گذاری می‌کنیم.
۲ Define $\phi : \mathcal{P}(A) \to \{0,1\}^n$ by $\phi(B)_i = 1 \iff a_i \in B$. هر زیرمجموعه را به یک رشتهٔ بیتی متناظر می‌کنیم: بیتِ $i$ نشانِ حضورِ $a_i$.
۳ $\phi$ is a bijection: every subset gives a unique bit-string, and every bit-string gives a unique subset. این نگاشت دوسویی است: هر زیرمجموعه رشتهٔ بیتِ یکتا می‌دهد و برعکس.
۴ $|\{0,1\}^n| = 2^n$ (each bit has 2 choices, $n$ independent bits). تعدادِ رشته‌های بیتِ طولِ $n$ برابرِ $2^n$ است — هر بیت ۲ انتخاب، $n$ بیتِ مستقل.
۵ $\therefore\; |\mathcal{P}(A)| = |\{0,1\}^n| = 2^n$. تعدادِ زیرمجموعه‌های $A$ برابرِ $2^n$ است. ∎

۸فرمول ترکیب‌ها

فرمول ترکیب‌ها
$$\binom{n}{k} = \frac{n!}{k!\,(n-k)!}$$
شمارشِ دوگانه
۱ Let $P(n, k) = $ number of ordered $k$-tuples from $n$ distinct elements. Then $P(n,k) = n(n-1)\cdots(n-k+1) = \dfrac{n!}{(n-k)!}$. تعداد انتخابِ $k$ عنصر با ترتیب.
۲ Each $k$-element subset can be ordered in $k!$ ways, so $P(n,k) = \binom{n}{k} \cdot k!$. هر مجموعهٔ $k$تایی، $k!$ جای‌گشت دارد.
۳ Solve: $\binom{n}{k} = \dfrac{P(n,k)}{k!} = \dfrac{n!/(n-k)!}{k!} = \dfrac{n!}{k!(n-k)!}$. با حل، فرمولِ ترکیب به‌دست می‌آید. ∎

۹قضیه دوجمله‌ای

دوجمله‌ای
$$(x + y)^n = \sum_{k=0}^{n} \binom{n}{k} x^{n-k} y^k$$
اثباتِ ترکیبیاتی
۱ $(x+y)^n = \underbrace{(x+y)(x+y)\cdots(x+y)}_{n \text{ factors}}$. $(x+y)^n$ حاصلِ ضربِ $n$ عاملِ $(x+y)$ است.
۲ Expanding, each term picks $x$ or $y$ from each factor. A term with $k$ copies of $y$ and $(n-k)$ copies of $x$ has coefficient $x^{n-k} y^k$. هر جمله از یک انتخاب دل‌خواه می‌آید: از کدام پرانتز $y$ بگیریم؟
۳ The number of ways to choose which $k$ factors contribute $y$ is $\binom{n}{k}$. تعداد راه‌های انتخابِ $k$ پرانتز از $n$ پرانتز — همان فرمولِ ترکیب.
۴ Summing over $k = 0, \ldots, n$: $(x+y)^n = \sum_{k=0}^{n} \binom{n}{k} x^{n-k} y^k$. با جمع بر $k$، قضیهٔ دوجمله‌ای ثابت می‌شود. ∎

۱۰گویا نبودن √۲

گویا نبودن √۲
$$\cNeg\,\cEx\, p, q \in \cZ,\; q \cNeq 0 \;:\; \sqrt{2} = \tfrac{p}{q},\; \gcd(p, q) = 1$$
به‌تناقض
۱ Suppose, for contradiction, $\sqrt{2} = \tfrac{p}{q}$ with $p, q \in \cZ$, $q \cNeq 0$, $\gcd(p, q) = 1$. فرضِ تناقض: $\sqrt{2}$ گویاست و کسر را ساده کرده‌ایم.
۲ Squaring: $2 = \tfrac{p^2}{q^2}$, hence $p^2 = 2q^2$. به‌توانِ ۲: $p^2 = 2q^2$، پس $p^2$ زوج است.
۳ $2 \mid p^2 \cImp 2 \mid p$ (since $\text{odd}^2 = \text{odd}$). Write $p = 2m$. اگر $p$ فرد باشد، $p^2$ هم فرد است؛ پس $p$ باید زوج باشد. پس $p = 2m$.
۴ Substitute: $2q^2 = (2m)^2 = 4m^2$, hence $q^2 = 2m^2$. جای‌گذاری: $q^2 = 2m^2$، پس $q^2$ هم زوج است.
۵ By the same argument, $2 \mid q^2 \cImp 2 \mid q$. همان استدلال، برای $q$.
۶ So $2 \mid p \cAnd 2 \mid q$, contradicting $\gcd(p, q) = 1$. هر دو زواند، پس مقسوم‌علیه‌مشترکِ بزرگ‌تر از ۱ دارند — در تناقض با گامِ ۱.
۷ The supposition is false; $\therefore\; \sqrt{2} \notin \cQ$. فرضِ تناقض رد شد؛ $\sqrt{2}$ گویا نیست. ∎

۱۱نامتناهی بودن اعداد اول

نامتناهی بودن اعداد اول
$$\cAll\, n \in \cN \;:\; \cEx\, \text{prime } p > n$$
اثباتِ اقلیدس — به‌تناقض
۱ Suppose the set of primes is finite: $\{p_1, p_2, \ldots, p_k\}$. فرضِ تناقض: اعدادِ اول متناهی‌اند و فهرست می‌شوند.
۲ Define $N = p_1 \cdot p_2 \cdots p_k + 1$. عددِ $N$ = ضربِ همهٔ اول‌های فهرست + ۱ را می‌سازیم.
۳ By FTA, $N$ has a prime divisor $q$ (every integer $> 1$ has one — proved separately). هر عددِ بزرگ‌تر از ۱ یک مقسوم‌علیهٔ اول دارد — پس $N$ هم دارد: $q$.
۴ If $q = p_i$ for some $i$, then $p_i \mid (p_1 \cdots p_k)$ and $p_i \mid N$, so $p_i \mid (N - p_1\cdots p_k) = 1$ — impossible. اگر $q$ در فهرست باشد، باید بر ۱ بخش باشد — محال.
۵ So $q \notin \{p_1, \ldots, p_k\}$, contradicting the assumption that the list was complete. پس $q$ اولی است که در فهرست نیست — در تناقض با کامل‌بودنِ فهرست.
۶ $\therefore$ the set of primes is infinite. مجموعهٔ اعدادِ اول متناهی نیست. ∎
نکتهٔ ظریف $N = p_1\cdots p_k + 1$ لزوماً اول نیست؛ فقط کافی است که یک عاملِ اولِ جدید داشته باشد.

۱۲قاعده بخشش بر ۳

بخشش بر ۳
$$n = \sum_{i=0}^{k} d_i \cdot 10^i \;:\quad 3 \cDiv n \;\cIff\; 3 \cDiv \sum_{i=0}^{k} d_i$$
حسابِ پیمانه‌ای
۱ Key: $10 \cEquiv 1 \pmod{3}$, since $10 = 3 \cdot 3 + 1$. کلید: $10$ به‌پیمانهٔ ۳ با ۱ هم‌نهشت است — چون $10 = 3\cdot 3 + 1$.
۲ Therefore $10^i \cEquiv 1^i = 1 \pmod{3}$ for all $i \ge 0$. اگر $a \cEquiv b$، آن‌گاه $a^i \cEquiv b^i$.
۳ So $n = \sum d_i \cdot 10^i \cEquiv \sum d_i \cdot 1 = \sum d_i \pmod{3}$. پس $n$ به‌پیمانهٔ ۳ با جمعِ ارقامش هم‌نهشت است.
۴ Hence $n \cEquiv 0 \pmod{3} \cIff \sum d_i \cEquiv 0 \pmod{3}$, i.e. $3 \cDiv n \cIff 3 \cDiv \sum d_i$. پس $3$ بر $n$ بخش است iff بر جمعِ ارقامش بخش است. ∎
تعمیم چون $10 \cEquiv 1 \pmod{9}$ نیز برقرار است، همان قاعده برای ۹ هم کار می‌کند. برای ۱۱: $10 \cEquiv -1 \pmod{11}$، که قاعدهٔ جمعِ تفاضلی ارقام را می‌دهد.

۱۳قضیه بنیادی حساب

تجزیهٔ یکتای اول
$$\cAll\, n \in \cN,\; n > 1 \;:\; \cEx\, p_1 \le \cdots \le p_k \;\text{prime},\; n = p_1 \cdots p_k,\;\text{unique up to order}$$
بخشِ ۱ — وجود (استقرای قوی)
۱ Base: $n = 2$ is prime. ✓ پایهٔ استقرا: $2$ خودش اول است.
۲ Inductive step: assume every $m$ with $2 \le m < n$ has a prime factorization. Consider $n$. گامِ استقرا: فرض می‌کنیم هر $m$ کوچک‌تر از $n$ تجزیهٔ اول دارد.
۳ Either $n$ is prime (done), or $n = a \cdot b$ with $1 < a, b < n$. یا $n$ خودش اول است (تمام)، یا $n = a\cdot b$ با $1 < a, b < n$.
۴ By the inductive hypothesis, $a$ and $b$ have prime factorizations; concatenating gives one for $n$. از فرضِ استقرا، $a$ و $b$ تجزیهٔ اول دارند؛ چسباندنِ آن‌ها تجزیهٔ $n$ را می‌دهد. ∎
بخشِ ۲ — یکتایی (لمِ اقلیدس)
۱ Euclid's lemma (proved via Bézout, see §14): if $p$ prime and $p \mid ab$, then $p \mid a \cOr p \mid b$. لمِ اقلیدس: اگر $p$ اول و بر $ab$ بخش باشد، پس بر $a$ یا بر $b$ بخش است.
۲ Suppose $n = p_1 \cdots p_k = q_1 \cdots q_l$ are two prime factorizations. فرض: دو تجزیهٔ اولِ متفاوت برای $n$ داریم.
۳ $p_1 \mid q_1 \cdots q_l$. By Euclid's lemma applied repeatedly, $p_1 \mid q_i$ for some $i$. Both are prime, so $p_1 = q_i$. اگر $p_1$ اول و بر $q_i$ اول بخش‌ باشد، آن‌گاه $p_1 = q_i$.
۴ Cancel $p_1 = q_i$ from both sides. Repeat with $p_2, \ldots$ until all are matched. $p_1 = q_i$ را از دو طرف ساده می‌کنیم و با $p_2, \ldots$ همین کار را تکرار می‌کنیم.
۵ Thus $k = l$ and the factorizations agree up to order. پس $k = l$ و تجزیه‌ها تا ترتیب یکسان‌اند. ∎

۱۴اتحاد بزو

پیش‌زمینه

ب.م.م (بزرگ‌ترین مقسوم‌علیهٔ مشترک) $\gcd(a, b)$ بزرگ‌ترین عدد صحیحی است که هم $a$ و هم $b$ بر آن بخش‌پذیرند. مثلاً $\gcd(12, 18) = 6$.

الگوریتمِ اقلیدسی: برای یافتنِ $\gcd(a, b)$، $a$ را بر $b$ بخش می‌کنیم: $a = bq + r$ با $0 \le r < |b|$. آن‌گاه $\gcd(a, b) = \gcd(b, r)$ — چون هر مقسوم‌علیهٔ مشترکِ $a$ و $b$ بر $r = a - bq$ هم بخش‌ است، و برعکس. این کار را تکرار می‌کنیم تا باقی‌مانده صفر شود.

اتحادِ بزو می‌گوید: ب.م.م را می‌توان به‌صورتِ ترکیبِ خطیِ $a$ و $b$ با ضرایبِ صحیح نوشت — یعنی $\gcd(a,b) = ax + by$ برای برخی $x, y \in \cZ$. این بدیهی نیست: مثلاً $\gcd(12, 18) = 6 = 18\cdot 1 + 12\cdot(-1)$.

اتحاد بزو برای هر دو عدد صحیحِ $a, b$ که هر دو صفر نباشند، ب.م.مِ آن‌ها را می‌توان به‌صورتِ ترکیبِ خطیِ $a$ و $b$ با ضرایبِ صحیح نوشت:
$$\cAll\, a, b \in \cZ,\; (a,b) \cNeq (0,0) \;:\; \cEx\, x, y \in \cZ \;:\; \gcd(a, b) = ax + by$$
الگوریتمِ اقلیدسی
۱ Division rule: $a = bq + r$ with $0 \le r < |b|$, and $\gcd(a, b) = \gcd(b, r)$. قاعدهٔ بخش‌کردن: $a = bq + r$ با باقی‌ماندهٔ $r$ کوچک‌تر از $|b|$. مقسوم‌علیهٔ مشترکِ $a, b$ همان مقسوم‌علیهٔ مشترکِ $b, r$ است.
۲ Iterate: $a = bq_1 + r_1$, $b = r_1 q_2 + r_2$, $\ldots$, until $r_{k} = 0$. Then $\gcd(a, b) = r_{k-1}$. تکرارِ بخش‌کردن: باقی‌مانده‌ها کم می‌شوند، پس الگوریتم خاتمه می‌یابد. آخرین باقی‌ماندهٔ ناصفر، همان ب.م.م است.
۳ Back-substitute: each $r_i = r_{i-2} - r_{i-1} q_i$ is a linear combination of the previous two remainders. جای‌گذاریِ رو‌به‌عقب: هر باقی‌مانده را با دو باقی‌ماندهٔ قبلی выраж می‌کنیم، و این زنجیره را تا $a$ و $b$ می‌کشیم.
۴ Unwinding to $a, b$: $\gcd(a, b) = r_{k-1} = ax + by$ for some $x, y \in \cZ$. در پایان، ب.م.م به‌صورتِ $ax + by$ با ضرایبِ صحیح درمی‌آید — همین اتحادِ بزو.
کاربرد — لمِ اقلیدس اگر $p$ اول، $p \mid ab$، $p \cNotDiv a$: آن‌گاه $\gcd(p, a) = 1$، پس از بزو $\cEx\, x, y : xp + ya = 1$. ضرب در $b$: $xpb + yab = b$. چون $p \mid xpb$ و $p \mid yab$ (چون $p \mid ab$)، پس $p \mid b$. این لم، یکتاییِ تجزیهٔ اول (§۱۳) را ثابت می‌کند.

۱۵قضیه ویلسن

پیش‌زمینه

هم‌نهشتی پیمانه‌ای: $a \cEquiv b \pmod{p}$ یعنی $a - b$ بر $p$ بخش‌پذیر است. مثلاً $7 \cEquiv 1 \pmod{3}$.

معکوسِ پیمانه‌ای: اگر $\gcd(a, p) = 1$، آن‌گاه $\cEx\, a^{-1}$ با $a \cdot a^{-1} \cEquiv 1 \pmod{p}$. از بزو: $ax + py = 1$، پس $a^{-1} \cEquiv x \pmod{p}$.

قضیهٔ ویلسن یک آزمونِ زیبا برای اول‌بودن است: $p$ اول است اگر و تنها اگر $(p-1)! \cEquiv -1 \pmod{p}$. مثلاً برای $p = 5$: $(5-1)! = 24 \cEquiv 4 \cEquiv -1 \pmod{5}$. ✓

ویلسن عددِ $p$ اول است اگر و تنها اگر $(p-1)!$ به‌پیمانهٔ $p$ با $-1$ هم‌نهشت باشد:
$$p \;\text{prime} \;\cIff\; (p - 1)! \cEquiv -1 \pmod{p}$$
جفت‌کردنِ معکوس‌ها
۱ For $p$ prime, every $a \in \{1, \ldots, p-1\}$ has a unique inverse mod $p$: $\cEx\, a^{-1} : a \cdot a^{-1} \cEquiv 1 \pmod{p}$. برای $p$ اول، هر $a$ در $\{1, \ldots, p-1\}$ معکوسِ پیمانه‌ای دارد — از بزو: $\gcd(a, p) = 1$ پس $ax + py = 1$ و $x = a^{-1}$.
۲ Self-inverse elements satisfy $a^2 \cEquiv 1 \pmod{p}$, i.e. $p \mid (a-1)(a+1)$. عنصرِ خود‌معکوس یعنی $a = a^{-1}$، یعنی $a^2 \cEquiv 1$، یعنی $p \mid (a-1)(a+1)$.
۳ By Euclid's lemma: $a \cEquiv 1 \cOr a \cEquiv -1 \pmod{p}$. So only $1$ and $p - 1$ are self-inverse. چون $p$ اول، لمِ اقلیدس می‌گوید $p \mid (a-1)$ یا $p \mid (a+1)$. پس تنها خود‌معکوس‌ها $1$ و $p-1$ هستند.
۴ Pair up $\{2, 3, \ldots, p-2\}$ as $(a, a^{-1})$; each pair contributes $1$ to the product. بقیهٔ اعداد را با معکوس‌هایشان جفت می‌کنیم — هر جفت در ضرب با هم $1$ می‌دهند.
۵ So $(p-1)! = 1 \cdot \underbrace{(2 \cdot 2^{-1}) \cdots ((p-2)(p-2)^{-1})}_{= 1} \cdot (p-1) \cEquiv 1 \cdot 1 \cdot (p-1) \cEquiv -1 \pmod{p}$. پس $(p-1)!$ = $1$ × (حاصلِ جفت‌ها = $1$) × $(p-1) \cEquiv -1 \pmod{p}$.

۱۶نامساوی کاشی-شوارتس

کاشی-شوارتس
$$\left(\sum_{i=1}^{n} a_i b_i\right)^{\!2} \le \left(\sum_{i=1}^{n} a_i^2\right)\!\left(\sum_{i=1}^{n} b_i^2\right), \quad \text{equality} \cIff\, a = \lambda b$$
دلتای نامنفی
۱ For all $t \in \cR$: $f(t) = \sum_{i=1}^{n} (a_i t + b_i)^2 \ge 0$ (sum of squares). تابعِ $f(t)$ مجموعِ چند مربع است، پس برای هر $t$ نامنفی است.
۲ Expand: $f(t) = \left(\sum a_i^2\right) t^2 + 2\left(\sum a_i b_i\right) t + \left(\sum b_i^2\right) = At^2 + Bt + C$. با قرار دادن $A = \sum a_i^2$، $B = 2\sum a_i b_i$، $C = \sum b_i^2$.
۳ $f(t) \ge 0$ for all $t \cImp$ discriminant $\Delta = B^2 - 4AC \le 0$. یک درجهٔ دومِ نامنفی، دلتای نامنفی دارد.
۴ Substitute: $4\left(\sum a_i b_i\right)^2 - 4\left(\sum a_i^2\right)\left(\sum b_i^2\right) \le 0$, hence $\left(\sum a_i b_i\right)^2 \le \left(\sum a_i^2\right)\left(\sum b_i^2\right)$. با جای‌گذاریِ $A, B, C$، نامساویِ کاشی-شوارتس به‌دست می‌آید. ∎
۵ Equality iff $\Delta = 0$, i.e. $f$ has a real root $t_0$, i.e. $\sum(a_i t_0 + b_i)^2 = 0$, i.e. $a_i t_0 + b_i = 0$ for all $i$, i.e. $a = \lambda b$. برابری iff $\Delta = 0$، یعنی $f$ ریشه دارد، یعنی همهٔ مربع‌ها صفرند، یعنی $a = \lambda b$. ∎

۱۷نامساوی میانگین حسابی-هندسی

AM-GM
$$\cAll\, x_1, \ldots, x_n \ge 0 \;:\; \frac{x_1 + \cdots + x_n}{n} \ge \sqrt[n]{x_1 \cdots x_n}, \quad \text{equality} \cIff\, x_1 = \cdots = x_n$$
استقرای به‌عقبِ کوشی
۱ Base $n = 2$: $\tfrac{a+b}{2} \ge \sqrt{ab}$, since $(\sqrt{a} - \sqrt{b})^2 \ge 0 \cImp a + b \ge 2\sqrt{ab}$. مربعِ هر عدد نامنفی است.
۲ Doubling step: if AM-GM holds for $n$, then for $2n$: $\frac{x_1 + \cdots + x_{2n}}{2n} = \frac{1}{2}\!\left(\frac{x_1 + \cdots + x_n}{n} + \frac{x_{n+1} + \cdots + x_{2n}}{n}\right) \ge \frac{1}{2}\!\left(\sqrt[n]{x_1 \cdots x_n} + \sqrt[n]{x_{n+1} \cdots x_{2n}}\right) \ge \sqrt[2n]{x_1 \cdots x_{2n}}$. اول از فرضِ $n$، سپس از $n=2$ برای دو ریشهٔ $n$اُم.
۳ So AM-GM holds for $n = 2^k$ for every $k$. با تکرارِ گامِ دو، AM-GM برای هر توانِ ۲ ثابت می‌شود.
۴ Backward step: take arbitrary $n$. Pick $k$ with $2^k > n$. Set $\bar{x} = \tfrac{x_1 + \cdots + x_n}{n}$ and pad the list with $2^k - n$ copies of $\bar{x}$ to get $2^k$ numbers. گامِ بازگشت: برای $n$ دل‌خواه، $k$ را با $2^k > n$ انتخاب می‌کنیم و لیست را با کپیِ میانگین تا $2^k$ عدد پُر می‌کنیم.
۵ Apply AM-GM to the $2^k$ numbers: $\bar{x} \ge \left(x_1 \cdots x_n \cdot \bar{x}^{2^k - n}\right)^{1/2^k}$. AM-GM را به $2^k$ عددِ پُر‌شده اعمال می‌کنیم.
۶ Raise to $2^k$: $\bar{x}^{2^k} \ge (x_1 \cdots x_n)\, \bar{x}^{2^k - n}$. Divide by $\bar{x}^{2^k - n}$ (if $\bar{x} > 0$): $\bar{x}^n \ge x_1 \cdots x_n$, hence $\bar{x} \ge \sqrt[n]{x_1 \cdots x_n}$. به‌توانِ $2^k$ و ساده‌سازی: $\bar{x}^n \ge x_1\cdots x_n$، پس میانگینِ حسابی ≥ میانگینِ هندسی. ∎
۷ Equality iff all $2^k$ padded numbers are equal, i.e. $x_1 = \cdots = x_n = \bar{x}$. برابری iff همهٔ $x_i$ برابر باشند. ∎

۱۸اصل استقرای ریاضی

اصل استقرا
$$\big(P(1) \;\cAnd\; \cAll\, n \ge 1 : (P(n) \cImp P(n+1))\big) \;\cImp\; \cAll\, n \ge 1 : P(n)$$
از اصلِ خوش‌ترتیبی — به‌تناقض
۱ Assume $P(1)$ and $\cAll\, n : P(n) \cImp P(n+1)$, but $\cNeg\,\cAll\, n : P(n)$. فرضِ تناقض: $P$ برای همه درست نیست.
۲ Then $S = \{n \in \cN : \cNeg\, P(n)\}$ is nonempty. مجموعهٔ $S$ از اعدادی که $P$ برایشان نادرست است، ناتهی است.
۳ By the well-ordering principle, $S$ has a least element $m$. هر زیرمجموعهٔ ناتهی از $\cN$ کمینه دارد.
۴ $m \cNeq 1$, since $P(1)$ holds. So $m \ge 2$, i.e. $m - 1 \in \cN$. $m \neq 1$ چون $P(1)$ درست است؛ پس $m \ge 2$ و $m-1 \in \cN$.
۵ Since $m$ is least, $m - 1 \notin S$, so $P(m - 1)$ holds. چون $m$ کمینه است، $m-1 \notin S$، پس $P(m-1)$ درست است.
۶ By the inductive hypothesis, $P(m-1) \cImp P(m)$. So $P(m)$ holds — but $m \in S$ means $\cNeg\, P(m)$. Contradiction. از یک‌سو $P(m-1)$ درست است و استقرا $P(m)$ را می‌دهد؛ از سویِ دیگر $m \in S$ می‌گوید $P(m)$ نادرست است.
۷ So $S = \emptyset$, i.e. $\cAll\, n \ge 1 : P(n)$. پس $S$ تهی است و $P$ برای همهٔ $n$ درست است. ∎
سه نوع استقرا
  • ضعیف: $P(n) \cImp P(n+1)$.
  • قوی: $P(1) \cAnd \cdots \cAnd P(n) \cImp P(n+1)$ — در §۱۳ به‌کار رفت.
  • کامل: $\cAll\, k < n : P(k) \cImp P(n)$.
هر سه به اصلِ خوش‌ترتیبی معادل‌اند.

۱۹قضیه تالس

تالس اگر $A, B, C$ سه نقطه روی یک دایره باشند و $AC$ قطر باشد، آن‌گاه $\angle ABC = \pi/2$.
$$AC \text{ diameter} \;\cImp\; \angle ABC = \tfrac{\pi}{2}$$
از مرکزِ دایره
۱ Let $O$ be the center, so $|OA| = |OB| = |OC| = r$. نقطهٔ $O$ مرکزِ دایره و $r$ شعاع است.
۲ Since $|OA| = |OB|$, triangle $OAB$ is isosceles, so $\angle OAB = \angle OBA$. Call both $\alpha$. مثلثِ $OAB$ متساوی‌الساقین است — زاویه‌های قاعده برابرند.
۳ Likewise $|OB| = |OC|$, so triangle $OBC$ is isosceles, $\angle OBC = \angle OCB$. Call both $\beta$. مثلثِ $OBC$ هم متساوی‌الساقین است — زاویه‌های قاعده را $\beta$ می‌نامیم.
۴ In triangle $ABC$: $\alpha + \beta + \angle ABC = \pi$. But $\angle ABC = \alpha + \beta$ (since $OB$ splits it). مجموعِ زاویه‌های $ABC$ برابرِ $\pi$ است و $\angle ABC = \alpha + \beta$ (چون $OB$ آن را می‌شکافد).
۵ So $2(\alpha + \beta) = \pi$, hence $\angle ABC = \alpha + \beta = \pi/2$. پس $2(\alpha + \beta) = \pi$ و $\angle ABC = \pi/2$. ∎

۲۰قضیه مثلث متساوی‌الساقین

متساوی‌الساقین در یک مثلث، دو زاویه برابرند اگر و تنها اگر دو ضلعِ روبرویشان برابرند.
$$|AB| = |AC| \;\cIff\; \angle B = \angle C$$
($\cImp$) از تقارن
۱ Assume $|AB| = |AC|$. Reflect the triangle across the angle bisector of $\angle A$. خطِ تقارن، نیمسازِ زاویهٔ $A$ است.
۲ The reflection swaps $B \leftrightarrow C$ (since $|AB| = |AC|$) and fixes $A$. این بازتاب $B$ و $C$ را جابه‌جا می‌کند و $A$ را ثابت نگه می‌دارد.
۳ Reflections preserve angles, so $\angle B = \angle C$. بازتاب زاویه‌ها را حفظ می‌کند، پس $\angle B = \angle C$. ∎
($\cImpL$) به‌تناقض
۱ Assume $\angle B = \angle C$ but $|AB| \cNeq |AC|$, say $|AB| > |AC|$. فرضِ تناقض: $\angle B = \angle C$ ولی $|AB| > |AC|$.
۲ Mark $D$ on $AB$ with $|AD| = |AC|$. Then triangle $ADC$ is isosceles, so $\angle ACD = \angle ADC$. نقطهٔ $D$ روی $AB$ با $|AD| = |AC|$؛ مثلثِ $ADC$ متساوی‌الساقین است.
۳ But $\angle ADC = \angle DCB + \angle DCB' = \pi - \angle B$ (exterior angle), and $\angle ACD = \angle C - \angle DCB$... contradiction after chasing. تعقیبِ زاویه‌ها به تناقج می‌رسد.

۲۱فرمول مساحت هرون

هرون مساحتِ مثلثی با ضلع‌های $a, b, c$ و نیم‌محیط $s = \tfrac{a+b+c}{2}$:
$$K = \sqrt{s(s-a)(s-b)(s-c)}$$
از قانون کسینوس و جبر
۱ $K = \tfrac{1}{2}ab\sin C$. So $K^2 = \tfrac{1}{4}a^2 b^2 \sin^2 C = \tfrac{1}{4}a^2 b^2 (1 - \cos^2 C)$. مساحت از فرمولِ $K = \tfrac{1}{2}ab\sin C$؛ با قرینه‌سازیِ پیتاگوراس، $\sin^2 C = 1 - \cos^2 C$.
۲ By law of cosines: $\cos C = \tfrac{a^2 + b^2 - c^2}{2ab}$. از قانونِ کسینوس‌ها، $\cos C$ را به‌دست می‌آوریم.
۳ So $16 K^2 = 4a^2 b^2 - (a^2 + b^2 - c^2)^2 = (2ab - a^2 - b^2 + c^2)(2ab + a^2 + b^2 - c^2) = (c^2 - (a-b)^2)((a+b)^2 - c^2)$. تفریقِ مربعِ کامل از مربعِ کامل.
۴ Factor: $= (c - a + b)(c + a - b)(a + b - c)(a + b + c)$. با فاکتورگیریِ هر کدام به‌صورتِ اختلافِ مربع‌ها، چهار فاکتور می‌گیریم.
۵ With $s = \tfrac{a+b+c}{2}$: $c - a + b = 2(s - a)$, $c + a - b = 2(s - b)$, $a + b - c = 2(s - c)$, $a + b + c = 2s$. So $16 K^2 = 16\, s(s-a)(s-b)(s-c)$. با تعریفِ $s = \tfrac{a+b+c}{2}$، هر فاکتور را به‌صورتِ $2(s - \cdot)$ بازنویسی می‌کنیم.
۶ Hence $K = \sqrt{s(s-a)(s-b)(s-c)}$. فرمولِ هرون ثابت شد. ∎

۲۲قضیه بطلمیوس

بطلمیوس برای چهارضلعی محاطی $ABCD$:
$$|AC|\cdot|BD| = |AB|\cdot|CD| + |AD|\cdot|BC|$$
ساختِ نقطهٔ $E$
۱ Choose $E$ inside $ABCD$ with $\angle ABE = \angle DBC$ and $\angle BAE = \angle BDC$. ساختِ مثلثِ شبیه به $\triangle BDC$ درونِ $\triangle ABC$.
۲ Then $\triangle ABE \sim \triangle DBC$, so $|AB|/|DB| = |AE|/|DC| = |BE|/|BC|$, giving $|AE|\cdot|BD| = |AB|\cdot|CD|$. از تشابهِ $\triangle ABE \sim \triangle DBC$: $|AE|\cdot|BD| = |AB|\cdot|CD|$.
۳ Also $\triangle ABD \sim \triangle EBC$ (sharing $\angle ABD = \angle EBC$ and matching angles), so $|AD|/|EC| = |BD|/|BC|$, giving $|EC|\cdot|BD| = |AD|\cdot|BC|$. از تشابهِ $\triangle ABD \sim \triangle EBC$: $|EC|\cdot|BD| = |AD|\cdot|BC|$.
۴ Add: $|AE|\cdot|BD| + |EC|\cdot|BD| = (|AE| + |EC|)\cdot|BD| = |AC|\cdot|BD| = |AB|\cdot|CD| + |AD|\cdot|BC|$. نقطهٔ $E$ روی $AC$ است، پس $|AE| + |EC| = |AC|$.

۲۳قضیه چوا

چوا در مثلث $ABC$، سه خطِ هم‌گذر از رأس‌ها به ضلعِ روبرو، در یک نقطه هم‌گر می‌شوند iff:
$$\frac{|BX|}{|XC|}\cdot\frac{|CY|}{|YA|}\cdot\frac{|AZ|}{|ZB|} = 1$$
از مساحت‌ها
۱ Let cevians $AX, BY, CZ$ meet at $P$. Then $\tfrac{|BX|}{|XC|} = \tfrac{[ABX]}{[ACX]} = \tfrac{[PBX]}{[PCX]} = \tfrac{[ABP]}{[ACP]}$. نسبتِ مساحت‌ها = نسبتِ قاعده‌ها وقتی ارتفاع یکی است.
۲ Likewise $\tfrac{|CY|}{|YA|} = \tfrac{[BCP]}{[ABP]}$ and $\tfrac{|AZ|}{|ZB|} = \tfrac{[ACP]}{[BCP]}$. همین استدلال برای دو سویِ دیگرِ مثلث.
۳ Multiply: $\tfrac{|BX|}{|XC|}\cdot\tfrac{|CY|}{|YA|}\cdot\tfrac{|AZ|}{|ZB|} = \tfrac{[ABP]}{[ACP]}\cdot\tfrac{[BCP]}{[ABP]}\cdot\tfrac{[ACP]}{[BCP]} = 1$. با ضربِ سه نسبت، مساحت‌ها ساده می‌شوند و حاصل ۱ می‌شود. ∎

۲۴فرمول سه‌تایی‌های فیثاغورسی

سه‌تایی‌های فیثاغورسی همهٔ سه‌تایی‌های اولِ فیثاغورسی (با $\gcd(a,b,c) = 1$) به‌صورت:
$$a = m^2 - n^2, \quad b = 2mn, \quad c = m^2 + n^2, \quad m > n \ge 1,\; \gcd(m,n)=1,\; m \cNeq n \pmod{2}$$
تجزیهٔ پارامتری
۱ Assume $a^2 + b^2 = c^2$ with $\gcd(a,b,c) = 1$. Then exactly one of $a, b$ is even (else $c$ even, contradicting primitivity). WLOG $b$ even, $a$ odd. در یک سه‌گانهٔ اول، دقیقاً یکی از $a, b$ زوج است؛ بدون کاستگیِ کلی $b$ را زوج و $a$ را فرد می‌گیریم.
۲ $b^2 = c^2 - a^2 = (c-a)(c+a)$. Since $a, c$ odd, $c - a$ and $c + a$ are both even. Write $c - a = 2u$, $c + a = 2v$, so $b^2 = 4uv$, i.e. $(b/2)^2 = uv$. $b^2 = (c-a)(c+a)$؛ چون $a, c$ فرد، دو فاکتور زوج‌اند و $b^2/4 = uv$.
۳ $\gcd(u, v) = 1$ (since $\gcd(a, c) = 1$). So $uv$ is a square and $u, v$ coprime $\cImp$ $u = n^2$, $v = m^2$ for some $m, n$ with $\gcd(m, n) = 1$. اگر $\gcd(u,v)=1$ و $uv$ مربع باشد، هر کدام خود مربع‌اند.
۴ Then $a = v - u = m^2 - n^2$, $c = v + u = m^2 + n^2$, $b = 2mn$. The parity condition $m \cNeq n \pmod{2}$ ensures $a, c$ odd. با جای‌گذاری، فرمولِ پارامتری به‌دست می‌آید؛ $m, n$ باید مختلف‌الزوجیت باشند. ∎

۲۵واگرایی سری هارمونیک

واگرایی هارمونیک
$$H_n = \sum_{k=1}^{n} \frac{1}{k} \;\to\; \infty \quad (n \to \infty)$$
گروه‌بندیِ اورلر
۱ Group terms in blocks of length $2^j$: $\sum_{k=1}^{2^m} \tfrac{1}{k} = 1 + \sum_{j=1}^{m-1} \sum_{k=2^{j-1}+1}^{2^j} \tfrac{1}{k}$. جملات را در بلوک‌های طولِ $2^j$ گروه‌بندی می‌کنیم.
۲ Each block has $2^{j-1}$ terms, each $\ge \tfrac{1}{2^j}$, so $\sum_{k=2^{j-1}+1}^{2^j} \tfrac{1}{k} \ge 2^{j-1} \cdot \tfrac{1}{2^j} = \tfrac{1}{2}$. هر بلوک حداقل $\tfrac{1}{2}$ است.
۳ So $H_{2^m} \ge 1 + (m-1) \cdot \tfrac{1}{2} = \tfrac{m+1}{2} \to \infty$. $H_{2^m} \ge \tfrac{m+1}{2}$ و چون $m$ دل‌خواه است، $H_n$ واگراست. ∎

۲۶قانون تقابل درجه دوم

تقابل درجه دوم برای اول‌های فرد $p, q$:
$$\left(\tfrac{p}{q}\right)\!\left(\tfrac{q}{p}\right) = (-1)^{\tfrac{(p-1)(q-1)}{4}}$$
لمِ گاوس (طرح)
۱ Gauss's lemma: $\left(\tfrac{a}{p}\right) = (-1)^N$ where $N = $ number of residues $a, 2a, \ldots, \tfrac{p-1}{2}a$ that exceed $p/2$. لمِ گاوس، علامتِ لژاندر را به شمارشِ باقی‌مانده‌های بزرگ‌تر از $p/2$ وابسته می‌کند.
۲ Apply to $a = -1$: $\left(\tfrac{-1}{p}\right) = (-1)^{(p-1)/2}$, i.e. $-1$ is a QR mod $p$ iff $p \cEquiv 1 \pmod{4}$. برای $a = -1$: $-1$ مربعِ پیمانه‌ای است iff $p \cEquiv 1 \pmod 4$.
۳ Apply to $a = 2$: $\left(\tfrac{2}{p}\right) = (-1)^{(p^2-1)/8}$, i.e. $2$ is a QR mod $p$ iff $p \cEquiv \pm 1 \pmod{8}$. برای $a = 2$: $2$ مربعِ پیمانه‌ای است iff $p \cEquiv \pm 1 \pmod 8$.
۴ For odd primes $p, q$: count lattice points in $\{1 \le x \le \tfrac{p-1}{2},\; 1 \le y \le \tfrac{q-1}{2}\}$ above/below $y = (q/p)x$ in two ways. The parity counts give $\left(\tfrac{p}{q}\right)\!\left(\tfrac{q}{p}\right) = (-1)^{\tfrac{(p-1)(q-1)}{4}}$. شمارشِ نقاطِ شبکه در یک مستطیل، از دو طرف — ایدهٔ مرکزیِ اثباتِ آیزنشتاین.

۲۷قضیه کوچک فرما

فرما برای اولِ $p$ و $\gcd(a, p) = 1$:
$$a^{p-1} \cEquiv 1 \pmod{p}$$
از عملِ چرخشی
۱ Consider $\{1, 2, \ldots, p-1\}$ under multiplication mod $p$. Multiply each by $a$: the set $\{a, 2a, \ldots, (p-1)a\}$ is a permutation of $\{1, \ldots, p-1\}$ (since $a$ is invertible). ضرب در $a$ یک جایگشتِ پیمانه‌ای است.
۲ So $a \cdot 2a \cdots (p-1)a \cEquiv 1 \cdot 2 \cdots (p-1) \pmod{p}$, i.e. $a^{p-1} (p-1)! \cEquiv (p-1)! \pmod{p}$. ضربِ همهٔ اعضا در دو طرف: $a^{p-1}(p-1)! \cEquiv (p-1)! \pmod p$.
۳ Since $\gcd((p-1)!, p) = 1$ (as $p$ is prime and $p \nmid (p-1)!$), cancel: $a^{p-1} \cEquiv 1 \pmod{p}$. چون $(p-1)!$ نسبت به $p$ اول است، می‌توان ساده کرد: $a^{p-1} \cEquiv 1 \pmod p$. ∎

۲۸تعمیم اویلر قضیه فرما

اویلر برای $\gcd(a, n) = 1$:
$$a^{\varphi(n)} \cEquiv 1 \pmod{n}, \quad \varphi(n) = |\{k : 1 \le k \le n,\, \gcd(k,n) = 1\}|$$
گروهِ یکه‌های پیمانه‌ای
۱ Let $U_n = \{k \bmod n : \gcd(k, n) = 1\}$, a group of order $\varphi(n)$ under multiplication mod $n$. مجموعهٔ $U_n$ گروهِ یکه‌های پیمانه‌ای است.
۲ By Lagrange's theorem (order of subgroup divides group order), the order of any $a \in U_n$ divides $\varphi(n)$. قضیهٔ لاگرانژ: مرتبهٔ هر عضو، مرتبهٔ گروه را می‌بَرَد.
۳ So $a^{\varphi(n)} \cEquiv 1 \pmod{n}$. پس $a^{\varphi(n)} \cEquiv 1 \pmod n$ — تعمیمِ قضیهٔ فرما. ∎
قضیه لاگرانژ برای گروهِ متناهی $G$ و زیرگروهِ $H$: $|H|$ بر $|G|$ بخش‌ است. اثبات: تجزیهٔ $G$ به کلاس‌های هم‌بندیِ $H$ که همگی اندازهٔ $|H|$ دارند.

۲۹قضیه چهار مربع لاگرانژ

لاگرانژ هر عددِ طبیعی به‌صورتِ مجموعِ چهار مربعِ کامل قابل‌نوشتن است.
$$\cAll\, n \in \cN \;:\; \cEx\, a, b, c, d \in \cZ \;:\; n = a^2 + b^2 + c^2 + d^2$$
تقلیل به اول‌ها
۱ Identity (Euler): $(a^2+b^2+c^2+d^2)(w^2+x^2+y^2+z^2) = (aw-bx-cy-dz)^2 + (ax+bw+cz-dy)^2 + (ay-bz+cw+dx)^2 + (az+by-cx+dw)^2$. اتحادِ چهار مربعِ اویلر: مجموعِ چهار مربع، تحتِ ضرب، بسته است.
۲ So it suffices to prove for primes $p$. پس کافی است قضیه را برای اعدادِ اول ثابت کنیم — تجزیهٔ هر عدد به اول‌ها و اتحادِ اویلر.
۳ For prime $p$: there exist $x, y$ with $x^2 + y^2 + 1 \cEquiv 0 \pmod{p}$ (pigeonhole on $\{x^2\}$ and $\{-1 - y^2\}$). اصلِ لانه کبوتری: دو مجموعهٔ $\{x^2\}$ و $\{-1-y^2\}$ در $\mathbb{Z}_p$ هم‌پوشانی دارند.
۴ Construct a lattice in $\mathbb{Z}^4$ with $p^3$ points; by Minkowski (or direct counting), a non-zero point with norm $< 2p$ exists, giving $a^2+b^2+c^2+d^2 = p$. از قضیهٔ مینکوفسکی (یا شمارشِ مستقیم) یک نقطهٔ ناصفرِ شبکه با نُرمِ $< 2p$ پیدا می‌شود — پس $p$ مجموعِ چهار مربع است. ∎

۳۰مجموع دو مربع برای اول‌های ۱ mod ۴

فرما-اویلر اولِ فرد $p$ به‌صورت $a^2 + b^2$ قابل‌نوشتن iff $p \cEquiv 1 \pmod{4}$.
$$p = a^2 + b^2 \;\cIff\; p \cEquiv 1 \pmod{4}$$
($\cImp$) نزولِ بی‌نهایت
۱ If $p \cEquiv 1 \pmod{4}$, then $\left(\tfrac{-1}{p}\right) = 1$ (by quadratic reciprocity), so $\cEx\, x : x^2 \cEquiv -1 \pmod{p}$. از تقابلِ درجهٔ دوم، $-1$ مربعِ پیمانه‌ای است وقتی $p \cEquiv 1 \pmod 4$.
۲ So $\cEx\, m$ with $m^2 + 1 \cEquiv 0 \pmod{p}$, i.e. $p \mid (m^2 + 1)$. Pick smallest such $m$, $|m| < p/2$. پس $m$ وجود دارد با $p \mid m^2 + 1$؛ کوچک‌ترین را با $|m| < p/2$ برمی‌داریم.
۳ Set $n = (m^2 + 1)/p$. Then $n < p$ and $n \cdot p = m^2 + 1^2$ is a sum of two squares. $n = (m^2+1)/p$؛ آن‌گاه $np = m^2 + 1$ و $n < p$.
۴ Descent: if $n > 1$, construct a smaller $n' < n$ with the same property (using the two-square identity and division-with-remainder). Eventually $n = 1$, giving $p = a^2 + b^2$. نزولِ بی‌نهایتِ فرما — هر بار یک عددِ کوچک‌تر با همان ویژگی.
($\cImpL$)
۱ If $p = a^2 + b^2$, then $p \mid (a^2 + b^2)$ and $p \cNotDiv a, b$. So $(a b^{-1})^2 \cEquiv -1 \pmod{p}$, i.e. $-1$ is a QR mod $p$. اگر $p = a^2 + b^2$، آن‌گاه $-1$ مربعِ پیمانه‌ایِ $p$ است — از $a \cdot b^{-1}$.
۲ By Euler's criterion: $(-1)^{(p-1)/2} \cEquiv 1 \pmod{p}$, so $p \cEquiv 1 \pmod{4}$. از معیارِ اویلر، $(-1)^{(p-1)/2} = 1$، پس $p \cEquiv 1 \pmod 4$. ∎

۳۱شمارش‌پذیری گویاها

شمارش‌پذیری $\cQ$ مجموعهٔ اعدادِ گویا شمارش‌پذیر است.
$$\cEx\, f : \cN \to \cQ \;\text{bijection}$$
مورب‌سازیِ قطری
۱ List fractions $p/q$ with $q > 0$, $\gcd(p, q) = 1$, in a 2D grid by $(|p| + q)$. هر گویا را در سطرِ $|p| + q$ قرار می‌دهیم.
۲ Each diagonal $\{(p, q) : |p| + q = n\}$ is finite (has $O(n)$ elements). هر قطری متناهی است — تعدادِ گویاهایش $O(n)$.
۳ Enumerate diagonals in order $n = 1, 2, 3, \ldots$, within each diagonal list fractions left-to-right, skipping duplicates. قطری‌ها را به ترتیب می‌شماریم؛ تکراری‌ها را رد می‌کنیم.
۴ This gives a bijection $\cN \to \cQ$. So $\cQ$ is countable. پس یک دوسوییِ $\cN \to \cQ$ ساخته می‌شود — گویاها شمارش‌پذیرند. ∎

۳۲قضیه کانتور

کانتور برای هر مجموعهٔ $A$، مجموعهٔ توانی $\mathcal{P}(A)$ (یعنی مجموعهٔ همهٔ زیرمجموعه‌های $A$) به‌طور اکید بزرگ‌تر است — هیچ تابعِ پوشا از $A$ به $\mathcal{P}(A)$ وجود ندارد.
$$\cNotDiv\, f : A \to \mathcal{P}(A) \;\text{surjective}, \quad \text{i.e.}\; |A| < |\mathcal{P}(A)|$$
مجموعهٔ کانتور — به‌تناقض
۱ Suppose $f : A \to \mathcal{P}(A)$ is any function. Define $D = \{x \in A : x \notin f(x)\}$. مجموعهٔ کانتورِ $D$ — عناصری که در تصویرشان نیستند.
۲ If $f$ were surjective, $\cEx\, d \in A : f(d) = D$. اگر $f$ پوشا بود، یک $d \in A$ وجود داشت با $f(d) = D$.
۳ Is $d \in D$? If $d \in D$, then by definition $d \notin f(d) = D$ — contradiction. If $d \notin D$, then by definition $d \in f(d) = D$ — contradiction. پارادوکسِ راسل — $d$ نه در $D$ است و نه نیست.
۴ So no such $d$ exists, hence $f$ is not surjective. $\therefore\; |A| < |\mathcal{P}(A)|$. پس چنین $d$ای وجود ندارد و $f$ پوشا نیست — $|A| < |\mathcal{P}(A)|$. ∎

۳۳قضیه شرودر-برنشتاین

شرودر-برنشتاین اگر $\cEx\, f : A \to B$ injective و $g : B \to A$ injective، آن‌گاه $\cEx\, h : A \to B$ bijective.
$$(\cEx\, f : A \hookrightarrow B) \,\cAnd\, (\cEx\, g : B \hookrightarrow A) \;\cImp\; |A| = |B|$$
تجزیهٔ کانتور-برنشتاین
۱ Define $A_0 = A \setminus g(B)$, and recursively $A_{n+1} = g(f(A_n))$. Let $A^* = \bigcup_{n \ge 0} A_n$. $A_0$ را خارج از تصویرِ $g$ می‌گیریم و به‌طور بازگشتی $A_{n+1} = g(f(A_n))$؛ اجتماعِ همه را $A^*$ می‌نامیم.
۲ Define $h : A \to B$ by $h(x) = f(x)$ if $x \in A^*$, else $h(x) = g^{-1}(x)$. رویِ $A^*$ از $f$، رویِ بقیه از $g^{-1}$.
۳ $h$ is injective: on $A^*$, $f$ is injective; on $A \setminus A^*$, $g^{-1}$ is injective; and the two images are disjoint (by construction). $h$ یک‌به‌یک است — $f$ رویِ $A^*$، $g^{-1}$ رویِ بقیه، و تصویرهایشان جدا هستند.
۴ $h$ is surjective: any $y \in B$ is hit either by $h(g(y)) = y$ (if $g(y) \notin A^*$) or by some $x \in A^*$ (if $g(y) \in A^*$). $h$ پوشا است — هر $y \in B$ یا از $g^{-1}$ و یا از $f$ رویِ $A^*$ به‌دست می‌آید. ∎

۳۴قضیه مقدار میانی

مقدار میانی (IVT) اگر $f : [a, b] \to \cR$ پیوسته و $f(a) \cdot f(b) < 0$، آن‌گاه $\cEx\, c \in (a, b) : f(c) = 0$.
$$f \text{ continuous},\; f(a)\, f(b) < 0 \;\cImp\; \cEx\, c \in (a, b) : f(c) = 0$$
دو بخشی بودن — بایرکشن
۱ WLOG $f(a) < 0 < f(b)$. Set $a_0 = a, b_0 = b$. Recursively: $m_n = (a_n + b_n)/2$; if $f(m_n) < 0$ set $a_{n+1} = m_n, b_{n+1} = b_n$, else $a_{n+1} = a_n, b_{n+1} = m_n$. نصف می‌کنیم و سمتی که علامت عوض می‌کند را نگه می‌داریم.
۲ By construction $f(a_n) < 0 \le f(b_n)$ and $b_n - a_n = (b-a)/2^n \to 0$. در هر گام، $f(a_n) < 0 \le f(b_n)$ و طولِ بازه نصف می‌شود.
۳ $(a_n), (b_n)$ both converge to the same $c \in [a, b]$ (nested intervals, completeness). دو دنبالهٔ تو در تو به یک نقطهٔ $c \in [a,b]$ همگرا می‌شوند — از تکمیلِ اعدادِ حقیقی.
۴ By continuity: $f(c) = \lim f(a_n) \le 0$ and $f(c) = \lim f(b_n) \ge 0$, so $f(c) = 0$. از پیوستگی، $f(c) \le 0$ و $f(c) \ge 0$، پس $f(c) = 0$. ∎

۳۵قضیه مقدار میانگین

مقدار میانگین (MVT) اگر $f : [a, b] \to \cR$ در $[a, b]$ پیوسته و در $(a, b)$ مشتق‌پذیر باشد:
$$\cEx\, c \in (a, b) \;:\; f'(c) = \frac{f(b) - f(a)}{b - a}$$
از قضیهٔ رول
۱ Define $g(x) = f(x) - \dfrac{f(b) - f(a)}{b - a}(x - a)$. Then $g(a) = f(a)$ and $g(b) = f(a)$, so $g(a) = g(b)$. تابعِ $g$ را طوری می‌سازیم که در $a$ و $b$ برابر باشد.
۲ By Rolle's theorem: $\cEx\, c \in (a, b) : g'(c) = 0$. از قضیهٔ رول، چون $g(a) = g(b)$، یک $c \in (a,b)$ با $g'(c) = 0$ وجود دارد.
۳ $g'(c) = f'(c) - \dfrac{f(b) - f(a)}{b - a} = 0$, so $f'(c) = \dfrac{f(b) - f(a)}{b - a}$. با مشتق‌گیریِ $g$ و صفر قرار دادن: $f'(c) = \dfrac{f(b)-f(a)}{b-a}$. ∎
قضیه رول اگر $h(a) = h(b)$ و $h$ در $[a,b]$ پیوسته و در $(a,b)$ مشتق‌پذیر، آن‌گاه $\cEx\, c : h'(c) = 0$. اثبات: $h$ ماکزیمم/مینیممِ داخلی دارد (در غیر این صورت $h$ ثابت و $h' = 0$)، و در آن نقطه $h' = 0$ (لمِ فرما).

۳۶قضیه بنیادی حساب دیفرانسیل و انتگرال

FTC اگر $F(x) = \int_a^x f(t)\, dt$ و $f$ پیوسته باشد:
$$F'(x) = f(x), \quad \int_a^b f(x)\, dx = G(b) - G(a) \;\text{where}\; G' = f$$
بخشِ ۱ — $F' = f$
۱ $\dfrac{F(x+h) - F(x)}{h} = \dfrac{1}{h}\int_x^{x+h} f(t)\, dt$. نسبتِ تفاضلیِ $F$ = میانگینِ $f$ روی $[x, x+h]$.
۲ By MVT for integrals (since $f$ continuous): $\int_x^{x+h} f = h \cdot f(c_h)$ for some $c_h \in [x, x+h]$. مقدارِ میانگینِ انتگرال — $f$ در نقطه‌ای از بازه مقدارِ میانگین را می‌گیرد.
۳ As $h \to 0$, $c_h \to x$, so by continuity $\dfrac{F(x+h) - F(x)}{h} = f(c_h) \to f(x)$. Hence $F'(x) = f(x)$. وقتی $h \to 0$، $c_h \to x$ و از پیوستگی، $f(c_h) \to f(x)$؛ پس $F'(x) = f(x)$. ∎
بخشِ ۲ — $\int_a^b f = G(b) - G(a)$
۱ Let $G' = f$. By part 1, $F(x) = \int_a^x f$ also has $F' = f$. So $(G - F)' = 0$ on $[a, b]$. اگر $G' = f$، آن‌گاه از بخشِ ۱، $F' = f$ نیز هست؛ پس $(G-F)' = 0$.
۲ By MVT, $G - F$ is constant: $G(x) - F(x) = G(a) - F(a) = G(a) - 0 = G(a)$. از MVT، $G - F$ ثابت است؛ در $x = a$، $F(a) = 0$، پس $G(x) - F(x) = G(a)$.
۳ At $x = b$: $G(b) - F(b) = G(a)$, i.e. $F(b) = \int_a^b f = G(b) - G(a)$. در $x = b$: $\int_a^b f = F(b) = G(b) - G(a)$. ∎

۳۷قضیه تیلور

تیلور اگر $f$ تا مرتبهٔ $n+1$ مشتق‌پذیر باشد در اطرافِ $a$:
$$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k + R_n(x), \quad R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}$$
از MVT تکرارشده
۱ Let $T_n(x) = \sum_{k=0}^{n} \tfrac{f^{(k)}(a)}{k!}(x-a)^k$. Define $R_n(x) = f(x) - T_n(x)$. چندجمله‌ایِ تیلورِ $T_n$ و باقی‌ماندهٔ $R_n = f - T_n$ را تعریف می‌کنیم.
۲ Cauchy MVT applied to $R_n(x)$ and $g(x) = (x-a)^{n+1}$ on $[a, x]$: $\cEx\, c \in (a, x)$ with $\dfrac{R_n(x)}{(x-a)^{n+1}} = \dfrac{R_n^{(n+1)}(c)}{(n+1)!}$. قاعدهٔ کوشیِ MVT — نسبتِ دو تابع با مشتق‌های هم‌صفر.
۳ $T_n^{(n+1)} = 0$ (it's a polynomial of degree $n$), so $R_n^{(n+1)} = f^{(n+1)}$. $T_n$ چندجمله‌ایِ درجهٔ $n$ است، پس $T_n^{(n+1)} = 0$ و $R_n^{(n+1)} = f^{(n+1)}$.
۴ Substitute: $R_n(x) = \dfrac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}$. با جای‌گذاری، فرمولِ باقی‌ماندهٔ تیلور به‌دست می‌آید. ∎

۳۸فرمول بی‌ترتیبی‌ها

پیش‌زمینه

جایگشت از $\{1, \ldots, n\}$ یعنی یک چینشون از این $n$ عدد در یک ردیف — مثلاً برای $n=3$ جایگشت‌های $(1,2,3)$, $(2,3,1)$, $(3,1,2)$, ... . تعدادِ همهٔ جایگشت‌ها $n!$ است.

در یک جایگشت، عدد $i$ را نقطهٔ ثابت می‌گوییم اگر در جایِ $i$-ام نشسته باشد. مثلاً در $(2,1,3)$، عدد $3$ نقطهٔ ثابت است (و $1$ و $2$ نه).

بی‌ترتیبی (derangement) جایگشتی است که هیچ نقطهٔ ثابتی ندارد. مثلاً برای $n=3$ فقط $(2,3,1)$ و $(3,1,2)$ بی‌ترتیبی‌اند. می‌خواهیم $D_n$ = تعداد بی‌ترتیبی‌ها را به‌دست آوریم.

اصلِ شمول-استبعاد: برای شمارشِ اشیایی که هیچ‌کدام از ویژگی‌های $P_1, \ldots, P_n$ را ندارند، ابتدا همه را می‌شماریم، سپس آن‌هایی که حداقل یک ویژگی دارند را کم می‌کنیم، سپس آن‌هایی که حداقل دو ویژگی دارند را اضافه می‌کنیم (چون دوبار کم شده‌بودند)، و الی آخر — با علامتِ $+,-,+,-,\ldots$.

بی‌ترتیبی تعداد جایگشت‌های $\{1, \ldots, n\}$ بدون نقطهٔ ثابت:
$$D_n = n!\sum_{k=0}^{n} \frac{(-1)^k}{k!} \;\approx\; \frac{n!}{e}$$
یعنی تقریباً یک‌بر-$e$ِ همهٔ جایگشت‌ها بی‌ترتیبی‌اند.
اصلِ شمول-استبعاد
۱ Let $A_i = $ set of permutations fixing $i$. Then $D_n = n! - |A_1 \cup \cdots \cup A_n|$. بی‌ترتیبی = همهٔ جایگشت‌ها ($n!$) منهای آن‌هایی که حداقل یک نقطهٔ ثابت دارند (یعنی $\bigcup A_i$).
۲ By inclusion-exclusion: $|A_1 \cup \cdots \cup A_n| = \sum |A_i| - \sum |A_i \cap A_j| + \cdots$. شمول-استبعاد: تعدادِ اجتماع = جمعِ تک‌تک، منهایِ جمعِ دوتایی، به‌علاوهٔ جمعِ سه‌تایی، ... — با علامتِ $+,-,+,-,\ldots$.
۳ $|A_{i_1} \cap \cdots \cap A_{i_k}| = (n-k)!$ (fix $k$ points, permute the rest). There are $\binom{n}{k}$ such intersections. اگر $k$ نقطه ثابت باشند، بقیهٔ $n-k$ عدد دلخواه جایگشت می‌شوند — $(n-k)!$ حالت. و $\binom{n}{k}$ راه برای انتخابِ آن $k$ نقطه هست.
۴ So $|A_1 \cup \cdots \cup A_n| = \sum_{k=1}^{n} (-1)^{k+1} \binom{n}{k}(n-k)! = \sum_{k=1}^{n} (-1)^{k+1} \dfrac{n!}{k!}$. با قرار دادنِ $\binom{n}{k}(n-k)! = \dfrac{n!}{k!}$، اجتماع به‌صورتِ یک جمعِ متناوب درمی‌آید.
۵ Hence $D_n = n! - \sum_{k=1}^{n} (-1)^{k+1} \dfrac{n!}{k!} = n!\sum_{k=0}^{n} \dfrac{(-1)^k}{k!}$. As $n \to \infty$, $D_n/n! \to e^{-1}$. جمعِ نهایی همان بسطِ تیلورِ $e^{-1}$ است — پس نسبتِ بی‌ترتیبی‌ها به همهٔ جایگشت‌ها به $1/e$ میل می‌کند.

۳۹مسألهٔ تولد

مسألهٔ تولد در گروهی از $n$ نفر، احتمالِ هم‌تولدِ حداقل دو نفر:
$$P(n) = 1 - \prod_{k=0}^{n-1} \frac{365 - k}{365}$$
$P(23) > \tfrac{1}{2}$.
از متمم
۱ Compute complement: $P(\text{no shared birthday}) = \dfrac{365}{365} \cdot \dfrac{364}{365} \cdots \dfrac{365 - n + 1}{365} = \prod_{k=0}^{n-1} \dfrac{365 - k}{365}$. هر نفرِ جدید باید با همهٔ قبلی‌ها متفاوت باشد.
۲ So $P(n) = 1 - \prod_{k=0}^{n-1} \dfrac{365 - k}{365}$. متمم را از ۱ کم می‌کنیم تا احتمالِ هم‌تولدِ حداقل دو نفر به‌دست آید.
۳ Bound: $\prod_{k=0}^{n-1} (1 - k/365) \le \exp\!\left(-\sum_{k=0}^{n-1} k/365\right) = \exp\!\left(-\tfrac{n(n-1)}{730}\right)$. For $n = 23$: $\exp(-253/365) \approx 0.4995$, so $P(23) \approx 0.507 > 1/2$. تقریبِ $1 - x \le e^{-x}$.

۴۰اصل لانه کبوتری

لانه کبوتری اگر $n+1$ شیء در $n$ لانه قرار گیرد، آن‌گاه حداقل یک لانه دو شیء دارد.
$$|A| > |B| \;\cImp\; \cNotDiv\, f : A \to B \;\text{injective}$$
به‌تناقض
۱ Suppose $f : A \to B$ injective with $|A| = n+1, |B| = n$. Then $f$ maps $A$ onto $f(A) \subseteq B$ bijectively. فرضِ تناقض: $f$ یک‌به‌یک است؛ پس $A$ و $f(A) \subseteq B$ هم‌اندازه‌اند.
۲ So $|f(A)| = |A| = n + 1$. But $f(A) \subseteq B$ implies $|f(A)| \le |B| = n$. Contradiction: $n + 1 \le n$. $|f(A)| = n+1$ ولی $f(A) \subseteq B$ پس $|f(A)| \le n$ — تناقض. ∎
کاربرد در هر جمعِ ۳۶۷ نفر، حداقل دو نفر هم‌تولد هستند (۳۶۶ لانه برای ۳۶۵/۳۶۶ روزِ سال). در هر زیرمجموعهٔ $n+1$ تایی از $\{1, \ldots, 2n\}$، دو عدد یکی بر دیگری بخش‌ است (لانه‌ها: دسته‌های $\{k, 2k, 4k, \ldots\}$).
